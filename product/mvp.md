# MVP 设计文档

## 核心问题
什么是最小的、能让用户愿意付 $29 的版本？

## 答案
让用户在 10 分钟内看到自己和竞品的 AI 可见度差距，并拿到一份可以马上执行的行动清单。

---

## MVP 功能范围（保留）

1. 输入网站 URL → 自动扫描 → AI 可见度评分
2. 3 个竞品对比
3. 引用来源分析（竞品因为什么被引用）
4. 3 条具体可执行建议
5. 每周自动重新扫描 + 邮件报告

## MVP 砍掉（放到 v2）

- 内容自动生成
- 多地区追踪
- 白标报告
- 代理商计划
- ROI 追踪

---

## 技术栈

- 前端：Next.js
- 后端：Node.js + Express
- 数据库：Supabase
- AI 查询：OpenAI API + Perplexity API + Anthropic API
- 部署：Vercel（前端）+ Railway（后端）
- 支付：Stripe
- 邮件：Resend

---

## 开发时间线（4周）

- Week 1：核心查询引擎（向各 AI 平台发问题、解析品牌提及、基础评分）
- Week 2：Dashboard（注册登录、扫描界面、评分可视化）
- Week 3：建议生成（3条具体建议、引用来源展示）
- Week 4：自动化+上线（每周扫描、邮件报告、Stripe、发布）
