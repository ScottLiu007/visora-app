# GEO Visibility Engine — 完整产品设计文档
版本：v0.1 | 日期：2026年3月

---

## 一、产品愿景

### 一句话定位
帮助中小企业和独立开发者出现在 ChatGPT、Perplexity、Claude 的推荐结果里——用中国已验证的 GEO 方法论，以英文市场负担得起的价格。

### 为什么现在
| 维度 | 数据 |
|------|------|
| AI 搜索用户规模 | ChatGPT 周活 8 亿，Perplexity 月活 1 亿+ |
| 市场空白 | 现有工具最低 $99/月，全是企业向，无 indie hacker 产品 |
| 中国方法论优势 | 中国 GEO 产业已产业化，效果数据成熟，英文市场还在摸索 |
| 信息差窗口 | 约 6-12 个月，之后方法论将被英文市场自行发现 |

### 竞品定位
- 企业级：Scrunch($250+)、Profound($399+)、Bluefish(企业定制)
- 中端：Peec($105)、Semrush AI($99)
- 轻量：Rankscale($20)、Otterly($25)
- 你的位置：$29-49/月，监控+优化+内容执行，indie hacker 首选

---

## 二、目标用户

### 主要用户：英文市场独立开发者 / 小型 SaaS
- 1-5 人团队，有产品但缺营销资源
- 熟悉 SEO 概念，开始意识到 AI 搜索流量
- 月营销预算 $0-500
- 在 Reddit、Hacker News、Twitter/X 上活跃

### 核心痛点
- "我的产品在 ChatGPT 里根本不出现"
- "不知道为什么竞品被引用但我不被引用"
- "没时间学 GEO，需要直接告诉我做什么"

### 次要用户：中小型 B2B SaaS（5-50人）
- 有专职市场人员，但预算有限
- 正在从 SEO 过渡到 GEO

## 三、完整功能设计

### 模块 1：AI 可见度监测（Visibility Monitor）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 多平台检测 | ChatGPT、Perplexity、Claude、Gemini、Copilot | P0 |
| 品牌提及追踪 | 被提及几次、什么上下文 | P0 |
| AI 可见度评分 | 0-100 分，多平台加权 | P0 |
| 竞品对比 | 同时追踪 3-5 个竞品 | P0 |
| 情感分析 | 正面/中性/负面 | P1 |
| 每日/每周报告 | 自动生成，支持邮件推送 | P1 |
| 历史趋势 | 可见度变化曲线 | P2 |

### 模块 2：竞品引用分析（Citation Intelligence）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 引用来源溯源 | AI 引用了哪些网站来介绍竞品 | P0 |
| 内容结构分析 | 被引用内容的共同特征 | P0 |
| 引用缺口识别 | 竞品被引用但你没被引用的具体问题 | P0 |
| 引用频率排行 | 哪些第三方网站最影响 AI 推荐 | P1 |

### 模块 3：网站 AI 可读性审计（AI Readiness Audit）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 结构化数据检测 | 是否有 Schema.org 标注 | P0 |
| 内容可读性评分 | AI 爬虫能否正确解析 | P0 |
| FAQ 页面诊断 | 是否有 AI 友好的问答结构 | P0 |
| 修复优先级清单 | 按影响程度排列的具体建议 | P0 |

### 模块 4：内容优化引擎（Content Optimizer）—— 核心差异化
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 内容缺口分析 | 哪些主题你需要写但还没写 | P0 |
| AI 友好内容生成 | 一键生成符合 GEO 逻辑的文章草稿 | P0 |
| FAQ 生成器 | 自动生成 50 个常见问题+回答 | P0 |
| Schema 标注生成 | 自动生成结构化数据代码 | P1 |

### 模块 5：第三方存在感建设（Authority Building）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 第三方平台清单 | G2、Capterra、Reddit 等建议 | P1 |
| Reddit 策略建议 | 哪些 subreddit 应该参与 | P1 |
| PR 机会识别 | 哪些媒体在写你的细分领域 | P1 |

### 模块 6：ROI 追踪（Impact Dashboard）
| 功能 | 描述 | 优先级 |
|------|------|--------|
| AI 流量归因 | 从 AI 搜索来的访客占比 | P1 |
| 竞品对比报告 | 可向老板展示的一键报告 | P1 |
| 周度摘要邮件 | 自动发送进展摘要 | P1 |

## 五、用户旅程

```
注册 → 输入网站URL+品牌名+3个竞品
→ 首次全量扫描（约5分钟）
→ 首次诊断报告（评分+竞品对比+3个紧急问题）
→ 修复模式（选问题→看原因→生成解决方案）
→ 设置每周自动监测
→ 每周邮件报告
→ 看到可见度评分上升 → 付费转化
```

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| AI 平台封锁自动查询 | 多平台分散，控制查询频率 |
| 大厂快速跟进低价市场 | 先建用户基础，专注执行层 |
| GEO 算法失效 | 持续追踪变化，快速迭代 |
| 用户付费意愿不足 | 免费计划验证，先看激活率 |
